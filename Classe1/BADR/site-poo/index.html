PHP 8 · Programmation orientée objet

C'est quoi
l'orienté objet ?

Au lieu d'avoir des variables et des fonctions éparpillées, on regroupe les données et les actions d'une même chose dans un seul bloc : un objet. Un chat a un nom et un âge, et il sait miauler.

Voir mes exercices Essayer la fabrique

🏭 Une classe, c'est un moule

La classe décrit à quoi ressemble un chat. Chaque new fabrique un objet (une instance) à partir de ce moule, avec ses propres valeurs. Clique sur le bouton pour fabriquer des chats.

La classe (le moule)

class Chat
{
    public function __construct(
        private string $nom,
        private int $age,
    ) {}

    public function miauler(): string
    {
        return "Miaou, je suis {$this->nom} !";
    }
}

🧠 Les notions à connaître

Tout ce qu'on a vu en classe, résumé en une carte par notion.

📦 Propriétés et méthodes

Les propriétés sont les données de l'objet, les méthodes sont ses actions.

$chat->nom;        // propriété
$chat->miauler();  // méthode

🪞 $this

À l'intérieur de la classe, $this veut dire « l'objet sur lequel on travaille ».

return $this->nom;

🏗️ Le constructeur

Appelé automatiquement au new. Il remplit l'objet dès sa création.

$felix = new Chat('Félix', 3);

🔒 L'encapsulation

private cache une propriété. On la lit avec un getter et on la modifie avec un setter qui vérifie la valeur.

public function setAge(int $a): void {
    if ($a >= 0) $this->age = $a;
}

👨‍👦 L'héritage

Avec extends, un enfant récupère tout le code du parent. Un Chien est un Animal.

class Chien extends Animal {}

☝️ parent::

Un enfant peut réécrire une méthode, et quand même appeler la version du parent.

return parent::manger() . ' Puis toilette.';

🚫 abstract

Une classe abstraite ne peut pas être instanciée. Une méthode abstraite doit être écrite par chaque enfant.

abstract public function crier(): string;

🔁 Le polymorphisme

Une seule boucle, et chaque objet réagit à sa façon, sans aucun if.

foreach ($animaux as $a) {
    echo $a->crier();
}

🎲 static et __toString

Une méthode static s'appelle sur la classe. __toString() permet de faire echo $objet.

$d20 = De::deDonjon();
echo $d20;
